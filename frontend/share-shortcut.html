Create the Share Shortcut

Safari PWAs cannot appear in the iOS share sheet. A personal Shortcut gives your team the same share-to-TRIBLI flow.

  1. Open device setup, connect this phone and copy the Shortcut token.
  2. In Shortcuts, create Share to TRIBLI and enable it in the Share Sheet for Text, URLs and Images.
  3. Add Get URLs from Input and Get Images from Input when present.
  4. Add Get Contents of URL using the request contract below.
POST {ORIGIN}/api/share
Authorization: Bearer {DEVICE_TOKEN}
Content-Type: multipart/form-data

text  = Shortcut Input (text)
url   = first https URL in the input
image = first image (JPEG/PNG/WebP/HEIC)
TRIBLI never scrapes WhatsApp. A channel invite alone is not a specific opportunity, so include the caption or poster.
